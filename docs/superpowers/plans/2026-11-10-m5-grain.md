# M5 Grain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Physically driven film grain on the negative and the print, matched to the datasheet rms
granularity, scaled by format, new every frame; real time at UHD in Preview, exact in Full.

**Architecture:** A Boolean dye-cloud model per layer (fitted analytically to the datasheet curves at
load) is simulated per pixel by a hash-seeded cell scheme written once in a header shared by C++ and
Metal. Full runs it per pixel; Preview samples coherent, tileable plates the same simulation made.
Grain is two new pointwise stages in M4's staged pipeline (CPU) and two new post-ops in its fused
Metal passes.

**Tech Stack:** C++17, Metal Shading Language, doctest, CMake, Python 3 + PyMuPDF (digitiser), OFX
Support library.

**Spec:** docs/superpowers/specs/2026-11-10-m5-grain-design.md (read "Refinements from planning").

## Global Constraints

- Grain off, or Amount 0: output identical to M4 (bit-exact on CPU; GPU within 1e-3).
- Grain controls never re-bake the colour tables. Non-finite control values → default.
- Ranges: Amount 0–3 (1), Size 0.5–2 (1), Quality Preview/Full (Preview), Enable on (OFX default).
- Plates: 12 density levels per layer, 2048×2048, half precision; keep the last 2 sets.
- Speed (M4 Pro, UHD, worst-case noise frame): Preview all-on median ≤ 25 ms with grain ≤ 5 ms of
  it; Full ≤ 1 s/frame. M4's own benchmark (ceiling 22 ms, grain off) keeps passing.
- Datasheet PDFs are never committed; Python runs with `python -I`.
- Commits use the GitHub noreply email and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never merge or push to master.
- Build/test: `cmake --build build -j && ctest --test-dir build --output-on-failure` (4 suites:
  core, gpu, bundle, bundle_signature).

## Review Focus

1. A density halfway between two plate levels: Preview rms must not dip (coherent plates) — Task 4
   test "preview between levels".
2. A render window at an offset / a sub-window: grain identical to the same pixels of the full-frame
   render (absolute frame coordinates) — Tasks 3 and 5 tests "grain sub-window".
3. Densities outside the layer's range, below D-min, or non-finite: finite output, no NaN, clamped
   excess — Task 3 test "grain extreme densities".
4. Images wider than a plate (UHD > 2048): no visible seam at the wrap — Task 4 test "plates tile".
5. Two concurrent renders that need the same new plate set: generated once, no race — Task 6 test
   "concurrent renders share one plate set".

### Task 2: Boolean grain model and fit

**Files:**
- Create: `src/core/grain_model.hpp`, `src/core/grain_model.cpp`, `tests/core/test_grain_model.cpp`
- Modify: `src/core/lut.hpp` (BakedFilm gains `FilmGrain grain;`), `src/core/lut.cpp` (bakeFilm
  calls `makeGrain`), `CMakeLists.txt` (sources)

**Interfaces:**
- Consumes: `Stock::granularity`, `Stock::curve` (Task 1).
- Produces (grain_model.hpp):
  ```cpp
  struct GrainLayer {
    double d1 = 0;               // density of one point inside a cloud (saturating Boolean model)
    double rLoMm = 0, rHiMm = 0; // cloud radius at excess 0 and at excess dSpan, linear between
    double dMin = 0, dSpan = 0;  // layer curve's min density and (max - min)
    double radiusMm(double excess) const;
    // Poisson intensity (clouds/mm^2) giving mean excess: p = excess/d1 = 1 - exp(-lambda pi r^2)
    double lambdaPerMm2(double excess, double sizeMul = 1) const;
  };
  struct FilmGrain { std::array<GrainLayer, 3> negative, print; bool valid = false; };
  // Density covariance of the model at distance h (mm): d1^2 exp(-2 lambda pi r^2)(exp(lambda A(h)) - 1),
  // A(h) the overlap area of two discs of radius r at distance h.
  double grainCovariance(const GrainLayer& g, double excess, double hMm, double sizeMul = 1);
  double apertureRms(const GrainLayer& g, double excess, double apertureDiameterMm, double sizeMul = 1); // circular aperture
  double pixelRms(const GrainLayer& g, double excess, double pixelMm, double sizeMul = 1);              // square pixel
  // Factor that keeps the 48 um rms at `sizeMul`: apertureRms(.., 1) / apertureRms(.., sizeMul); 1 at excess 0.
  double sizeGain(const GrainLayer& g, double excess, double sizeMul, double apertureMm = 0.048);
  GrainLayer fitGrainLayer(const GranularityCurve& c, double dMin, double dSpan, double cloudRadiusMm, double apertureMm);
  // Memoised by stock id (mutex-guarded); valid == false when either stock has no granularity.
  FilmGrain makeGrain(const Stock& negative, const Stock& print);
  ```
- Aperture variance (exact, numerical quadrature over h in [0, 2r]):
  `sigma^2 = (1/Area^2) * integral C(h) * g_ap(h) * 2 pi h dh`, with `g_ap` the aperture's
  covariogram (circle: `2R^2 acos(h/2R) - (h/2) sqrt(4R^2 - h^2)`; square side a: average of
  `(a-|x|)(a-|y|)` over directions at radius h, or integrate in x,y directly).
- Fit: Nelder–Mead (deterministic fixed starts, like `fitSharpness`) on log-relative error over the
  layer's points; bounds `rLo, rHi ∈ [0.5, 2] × cloudRadius`, `d1 ∈ [1.05, 10] × dSpan`. Excess of a
  point = `density − dMin`, clamped to `[0, dSpan]`.

- [ ] **Step 1: Failing tests** in test_grain_model.cpp:

  - `"aperture rms matches a brute-force simulation"`: a GrainLayer with r = 0.004 mm, d1 = 3; at
    excess 0.3 and 1.5, simulate the model on a 2 mm × 2 mm grid at 0.5 µm (seeded std::mt19937),

  - `"size gain keeps strength"`: `apertureRms(.., 2) * sizeGain(.., 2) == apertureRms(.., 1)` within 1e-6 relative.
  - `"no granularity → invalid"`: stocks with `granularity` reset give `valid == false`.

### Task 3: Shared sampler and CPU Full grain

**Files:**
- Create: `src/metal/grain_common.h` (C/Metal common subset, like `shader_types.h`),
  `src/core/grain_sim.hpp`, `src/core/grain_sim.cpp`, `tests/core/test_grain.cpp`
- Modify: `src/core/film_spatial.hpp/.cpp`, `CMakeLists.txt`

**Interfaces:**
- Consumes: `FilmGrain`, `GrainLayer::lambdaPerMm2/radiusMm`, `pixelRms`, `sizeGain` (Task 2).
- Produces:
  - grain_common.h (one definition used by both compilers; `OF_U32` = `uint32_t`/`uint`):
    `of_hash(x)` (lowbias32: `x^=x>>16; x*=0x7feb352d; x^=x>>15; x*=0x846ca68b; x^=x>>16`),
    `of_hash2(a,b) = of_hash(a ^ of_hash(b))`, `of_unit(h)` = `(h >> 8) * 2^-24`,
    `of_poisson(mean, u)` (inverse CDF, capped at 64),
    `of_coverage(px, py, rPx, lambdaPx, cellPx, seed, periodCells)` → fraction of the pixel's 4×4
    stratified sub-samples (at `(i+0.5)/4`) inside any cloud. Cells of side `cellPx` (= the layer's
    largest radius at this Size, in px) are visited over the pixel ± r; cell (cx, cy) wraps modulo
    `periodCells` when > 0; its count is `of_poisson(lambdaPx·cellPx², of_unit(of_hash2(seed, cellId)))`
    and cloud i's centre is `cell origin + cellPx·(of_unit(of_hash2(cellHash, 2i)), of_unit(of_hash2(cellHash, 2i+1)))`.
    So counts rise monotonically with lambda and clouds at a lower density are a subset (coherence).
  - grain_sim.hpp:
    ```cpp
    enum class GrainStage { Negative = 0, Print = 1 };
    // Seed of one layer's clouds: hash of (frameSeed, stage, layer).
    uint32_t grainSeed(uint32_t frameSeed, GrainStage st, int layer);
    // Realised minus mean excess for one pixel (absolute frame coords), before Amount and sizeGain.
    // rPx < 0.25 -> Gaussian with pixelRms (Box-Muller from two hashes of (seed, px, py)).
    float grainDeviation(const GrainLayer& g, double excess, double pxPerMm, double sizeMul,
                         int px, int py, uint32_t seed, int periodCells = 0);
    ```
  - film_spatial.hpp: `enum class GrainQuality { Preview, Full };` SpatialControls gains
    `bool grain = false; double grainAmount = 1, grainSize = 1; GrainQuality grainQuality =
    GrainQuality::Preview; uint32_t frameSeed = 0; bool grainOn() const;` (`grain && grainAmount > 0`),
    `anyOn()` includes `grainOn()`; `sanitize` clamps Amount [0,3], Size [0.5,2];
    `uint32_t frameSeedFromTime(double time);` (hash of the double's bits);
    `void grainStage(Image4f& D, const WorkRect& rect, const BakedFilm& film, const SpatialControls& s, GrainStage st);`
    — `D_c += Amount · sizeGain · deviation`, excess = clamp(D_c − dMin, 0, dSpan), non-finite D left
    unchanged, no-op when `!s.grainOn()` or `!film.grain.valid`. Work pixel (i, j) is frame pixel
    (rect.x1 + i, rect.y1 + j). Task 3's grainStage always runs Full; Task 4 adds Preview.
  - renderFilm: `edgeEffect → grainStage(Negative) → printExposeStage … printDevelopStage → grainStage(Print) → finishStage`.
  Grain adds nothing to `spatialMarginPx` (it reads no neighbours). The core default `grain = false`
  keeps every existing test on its M4 path; the OFX default (on) is set in Task 7.

  NEG_GRAIN is set after the neg edge stage (or the last exposure stage), PRINT_GRAIN after the print
  scatter stage. When grain is the only effect on, the plan has one fused pointwise pass with no lobes.
